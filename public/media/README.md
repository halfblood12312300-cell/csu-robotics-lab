# 图片和短视频

把用于网站公开展示的图片和短视频上传到这个文件夹即可，不需要开通 R2。

1. 在 GitHub 本文件夹页面选择 **Add file → Upload files**。
2. 上传文件并提交到 `main`。
3. 等待 GitHub Actions 的 Pages 发布成功，然后刷新网站管理后台。
4. 文件会自动出现在“素材库”中，可选作首页图片、首页宣传视频、文章封面、正文插图或文章相册。

支持 JPG/JPEG、PNG、WebP、GIF、AVIF、MP4、WebM，也会扫描子文件夹。网页上传单个文件不得超过 **25 MiB**。建议使用英文、数字、连字符和下划线命名；中文和空格也会自动编码。请避免文件名使用 `#`、`?`、`%` 或反斜杠。

素材从 GitHub Pages 的网站地址读取。后台的素材详情可复制实际公开地址，不要把 GitHub 的 `blob` 文件查看页面地址当作图片或视频地址。

**这个仓库及其发布的素材公开可见。** 即使只把素材选入未发布草稿，文件也不会因此变成私有。请仅上传适合公开展示的内容；报名名单、联系方式导出、密钥和内部文件不放在这里。

文件替换、改名和删除在 GitHub 中操作；沿用原路径替换文件可以保留网站已有引用。删除或改名之前先检查首页和文章是否还在使用该文件。较长或较大的视频建议使用视频平台，并在文章中放链接。本流程不使用 Git LFS，构建会拒绝素材目录中的 LFS 指针文件。

更多说明见 [仓库素材维护指南](../../docs/repository-media.md)。
