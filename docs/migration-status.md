## 保留的内容与行为

- 沿用原网站外观、四个方向的展示内容、设备介绍和文章页面。
- 顶部“加入我们”是唯一固定报名入口。
- 通过 Hash 路由兼容项目型 Pages 地址，直接打开、刷新文章链接不依赖服务端动态路由。
- 报名与管理请求发送到配置的独立后端，管理员访问密钥与登录会话由后端验证。
- 公开仓库和静态构建仅包含代码、初始公开介绍及设备展示图片。
- 新的仓库素材流程适用于可公开的图片和短视频，提交和发布后素材文件可直接访问；草稿状态只保护后台文章数据，不保护仓库素材。

## 原站数据不会自动跟随源码

原站的 D1 生产记录与 R2 上传文件不在源码压缩包中。新建一个 Worker、D1 数据库或 R2 桶，也不会自动连接或复制原站的数据。

在切换正式报名入口之前，先保留旧站并由管理员完成以下准备：

1. 从旧管理后台导出内容备份和设置；报名名单单独导出到受控位置。
2. 保留上传素材原件。内容备份中的素材索引不是图片或视频本体。
3. 在新后端导入或重新发布内容；允许公开的图片、短视频按 [仓库素材维护](repository-media.md) 上传，并核对文章与首页所引用的素材地址。需要保持私有的原素材不要复制到公开仓库。
4. 如需把历史报名导入新数据库，应通过单独审核的管理迁移过程处理重复联系人和字段映射。当前后台没有承诺“上传旧 CSV 即自动导入”的功能；不得把报名 CSV 放进公开仓库。
5. 核对新站内容和报名读写结果，再确定旧站停止收新报名的时间，避免两个入口同时收集导致遗漏。

当前文档不声称历史报名、生产文章或上传素材已经迁移，也不改变旧站的访问权限与数据。
