# 后台内容维护说明

后台入口：<https://halfblood12312300-cell.github.io/csu-robotics-lab/#/admin?section=settings>。

使用管理员访问密钥登录，进入左侧 **网站设置**。网站内容和布局保存在 Cloudflare D1；保存这些设置不需要修改 GitHub 代码或重新构建前端。

## 可以修改哪些内容

| 分组 | 维护范围 |
| --- | --- |
| 站点与导航 | 浏览器标题、网站简介、实验室名称、副标题、Logo、顶部导航的文字与链接、加入我们入口、后台入口、页脚文案及链接 |
| 首页与布局 | 主题色、背景色、内容宽度、模块间距、圆角、顶部导航固定状态；七个首页模块的顺序和显示开关；首屏标题、介绍、图片/视频、按钮；数据概览；底部横幅 |
| 研究方向 | 新增、排序、显示或隐藏方向；卡片名称、英文说明、简介、标签；详情中的研究问题、输入输出、内容方向、步骤、例子、评估要点和关联文章 |
| 实验平台 | 设备卡片的显示、排序、标题、型号、数量、介绍、图片与跳转链接，以及图片来源说明 |
| 文章与影像 | 首页精选文章、展示数量、列数、栏目标题和跳转；文章分类及列表页说明；影像区从文章提取或手工选择素材 |
| 报名页面 | 开关与截止日期、联系方式、地点、页面布局、招新介绍、填写说明、关闭提示、同意说明、按钮和提交成功提示 |
| 报名表字段 | 新增、删除、排序、显示、必填、题目、输入提示、补充说明、宽度、长度限制和选项 |
| 内容备份 | 导出已保存的文章、素材索引与设置，或导出当前尚未保存的设置草稿 |

文章的正文、发布日期、草稿与发布状态在左侧 **文章管理** 修改。网站设置中的文章选择器决定首页优先展示哪些已发布文章；它不会发布草稿文章。

## 推荐的编辑流程

1. 进入对应分组，直接修改文字或使用列表按钮新增、调整顺序和显示状态。
2. 点击 **预览未保存修改**，查看首页或报名页，并切换桌面、手机尺寸。预览使用真正的页面组件；预览中的链接不会跳离编辑器，报名也不会提交。
3. 点击 **保存并发布设置**。看到保存成功后，打开或刷新公开页面查看结果。

切换网站设置内部的分组会保留草稿。离开后台栏目、退出或关闭页面时，存在未保存修改会提示。没有保存的预览不会影响访客看到的内容。

## 自定义报名表

支持单行文字、多行文字、邮箱、电话、网址、数字、日期、下拉选择、单选、多选和确认勾选，共 11 种类型。最多 40 个问题，单个选择题最多 60 个选项。

例如要增加“是否接触过 ROS”：

1. 打开 **报名表字段**，选择“单选”并添加问题。
2. 把问题标题改为“是否接触过 ROS”，设置“没有接触过”“上过相关课程”“做过实际项目”等选项。
3. 选择是否必填，调整到希望显示的位置。
4. 在报名页预览中确认，再保存。

选择题可以自行维护选项，也可以使用当前启用的研究方向。使用研究方向时，选项会跟随方向名称、顺序与显示状态更新。

**姓名和联系方式保留为必填基础字段。** 两者用于识别报名记录、避免重复报名及后续联系，不能删除或隐藏；题目名称、填写提示、说明和排列仍可以修改。其余问题可自由增删和隐藏。

报名是否开放由独立开关控制；截止日期按北京时间当天 23:59 判断。修改表单不会自动开放报名。

## 修改表单后的历史记录

每一条新报名都会保存当时的题目、题目类型、选项名称、填写答案、表单版本与同意说明。以后改题目或删选项，已经提交的记录仍按原题目显示。

旧版报名记录继续可查看。**报名管理 → 查看详情** 展示完整回答；搜索可匹配自定义问题的回答。CSV 导出包含自定义问题；不同版本中题目名称或类型不同的字段会分列保留，避免把含义不同的答案混在一起。

访客填写期间若管理员修改了表单，提交时会提示重新读取最新表单。页面保留已填写内容，访客核对更新后的问题和选项后可以再次提交。

## 图片和短视频

仍使用本仓库的 `public/media/`，无需启用 R2。上传新文件后，等待 GitHub Pages 发布完成，再刷新后台，在素材选择器中选择文件。现有素材可以在首屏、设备卡片、影像区、文章封面和正文中重复使用。

影像区选择“手工维护”时，可以自行增删、排序、设置图片/视频说明和跳转；选择“来自文章”时，自动使用已发布文章的素材。详见 [仓库素材维护](repository-media.md)。

## 同时编辑与保存失败

如果两个页面同时编辑，较晚保存的旧版本会收到冲突提示，不会覆盖别人已保存的设置。本页草稿会保留，可先导出，再载入最新设置并合并修改。

保存前会校验内容并指出对应分组或问题。校验失败或网络错误不会清空草稿。请在看到成功提示后再离开页面。

内容备份包含素材链接，不包含图片或视频原件；报名名单在 **报名管理** 单独导出。草稿导出用于保留和对照，当前界面不提供一键导入覆盖。

## 首次升级说明

这次升级通过新增数据库列保存动态报名快照，不删除或重写旧报名。旧网站设置会与默认配置合并，原有简介、首页素材、联系方式、地点、报名开关和截止日期继续使用。

GitHub Pages 与 Cloudflare Worker 分别部署，短暂先后更新时，编辑器会等待新后端就绪；刷新后台即可加载新的完整编辑功能。上线结果以 GitHub Actions 与 Workers Builds 的实际状态为准。
