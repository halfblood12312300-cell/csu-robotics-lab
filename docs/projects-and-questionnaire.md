# 首页轮播、拟开展项目与腾讯问卷

后台 → 网站设置 → 首页与布局：编辑原首图/视频以及额外轮播图片，可添加、排序、隐藏、删除和选择仓库素材。前台可滑动或点箭头和圆点浏览。保留原首图及原视频；默认添加 H2 官方展示图。

网站设置 → 拟开展项目：编辑院史馆导览、机器狗拿外卖两项规划，支持增删排序、显示、图片、名称和说明。原实验平台数据仍保留在原配置和设备文章，首页复用原平台区锚点。默认项目图为无照片的样式占位，避免误认为已经完成。

网站设置 → 报名页面：先在 https://wj.qq.com/ 创建并发布问卷，复制公开填写链接。选择腾讯问卷模式，填入链接并配置按钮和提示，开启报名后保存。国内访客可通过 GitHub Pages 同步副本打开外部链接，不依赖 Worker 实时连接。外部模式下本站原生提交被拒绝，历史报名记录保留。问卷问题、回收和导出均在腾讯问卷管理。关闭报名也要在腾讯问卷停止回收。快照同步约每15分钟触发，可能延迟。未提供真实问卷链接前保留现有原生报名模式。
