# 首页轮播、拟开展项目与外部问卷

后台 → 网站设置 → 首页与布局：编辑原首图/视频以及额外轮播图片，可添加、排序、隐藏、删除和选择仓库素材。前台可滑动或点箭头和圆点浏览。

网站设置 → 拟开展项目：编辑院史馆导览、机器狗拿外卖、机器人表演三项规划，支持增删排序、显示、图片、名称和说明。原实验平台数据仍保留在原配置和设备文章。默认项目图为无照片的样式占位。

网站设置 → 报名页面：当前选用问卷星，公开填写链接为 https://www.wjx.top/vm/rbkF28c.aspx#。数据库一次性迁移仅切换报名模式和链接、追加项目，保留原报名开关、截止日期和其他设置。若原报名未开放，需管理员打开开关并保存。可以在此改为其他受支持的问卷星或腾讯问卷公开填写链接，或切回原生报名。国内访客可通过 GitHub Pages 同步副本打开外部链接，不依赖 Worker 实时连接。外部模式下本站原生提交被拒绝，历史报名记录保留。问卷问题、回收和导出在问卷星管理；关闭报名也要在问卷星停止回收。快照同步约每15分钟触发，可能延迟。
